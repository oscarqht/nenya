Run code in page

Manage snippets to run manually in the popup.

Use nenyaFetch(url, init) for cross-origin requests that page fetch() cannot make because of CORS. It runs in Nenya's background and returns a fetch-like response with ok, status, headers, text(), and json().

const res = await nenyaFetch('https://api.example.com/data', {
  method: 'GET',
  credentials: 'include',
});

if (!res.ok) throw new Error(`${res.status} ${res.statusText}`);
const data = await res.json();
